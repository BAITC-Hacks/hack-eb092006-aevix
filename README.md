# Мини-скрипты для обращений и алертов

## Что внутри

- `classify_messages.py` читает пять обращений из `messages.txt`, определяет категорию (`справка`, `жалоба` или `другое`) по простым правилам и печатает черновик ответа.
- `filter_alerts.py` читает события из `events.json`, оставляет только события уровня `critical` и печатает их количество.

## Запуск

Нужен Python 3.9+:

```bash
python classify_messages.py
python filter_alerts.py
```

В результате первое приложение выводит пять классифицированных обращений с ответами, а второе — три критичных события и строку `критичных 3`.
